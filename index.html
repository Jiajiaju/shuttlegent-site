01 / INTERFACE

停靠在编辑器里的面板
对话、工具与改动都在编辑器内

点主工具栏上的 Shuttlegent 按钮打开面板。面板可以像细节面板一样停靠，也可以拖出多个会话窗口。

02 / CAPABILITIES

查询、批量修改、整理资源
改动先确认，可撤销

用中文描述要做的事，它调用编辑器工具完成。

01

看清关卡

查询 Actor、检查属性、读取日志，先弄清楚眼前发生了什么。

02

成批调整

摆放与排列 Actor，修改属性、分配材质，让同一件事一次做完。

03

理顺资源

查找资产与引用、调整材质参数、整理节点图、导出数据表。

04

先想后做

计划模式先出方案，批准后再改；挑图、配色、选材质时，用选择卡直接点选。

05

并行会话

多个会话同时进行，每个都能拖成独立窗口，像细节面板一样停靠。

改动的确认与撤销

写入前列出对象、字段、当前值与计划值，确认后在编辑器事务中执行。四种模式决定哪些写入先问你，删除、移动、改名始终要确认；“回到这里”可撤回一条消息之后的全部可撤销写入。

GET STARTED

安装步骤

  1. 01
    下载插件包从 GitHub Releases 下载 Shuttlegent-0.4.0-UE5.8-win64.zip，解压到项目的 Plugins 目录。运行时已在包内，不需要另外构建。
  2. 02
    启用并编译在 .uproject 中启用 Shuttlegent，重新生成工程文件并编译编辑器。
  3. 03
    打开面板点主工具栏播放按钮右侧的 Shuttlegent 标志。
  4. 04
    连接模型，开始对话在“连接一个模型”卡片里选 DeepSeek 填密钥，或选其他服务填地址和密钥。先用只读任务熟悉流程，再确认需要的修改。
