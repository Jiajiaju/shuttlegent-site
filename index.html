GET STARTED

装进你的编辑器。

  1. 01
    放入插件将 Shuttlegent 放到项目的 Plugins 目录。
  2. 02
    构建运行时与 Editor按插件 README 完成运行时打包与项目 Editor 编译。
  3. 03
    填写模型配置编辑器偏好设置 → Shuttlegent → General → Providers。
  4. 04
    打开面板，开始对话先用只读任务熟悉流程，再确认需要的修改。

支持 UE 5.8 / Windows；具体构建要求以插件 README 为准。
