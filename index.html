03 / YOUR MODEL, YOUR AGENT

模型与 Agent，
按会话自由组合。

内置 DeepSeek-V4.1-Flash 与 DeepSeek-V4-Pro，也可添加 OpenAI 协议、Anthropic 协议或兼容端点的模型。每个会话各自选择 Agent 与模型。

DeepSeek 内置模型OpenAI 协议与兼容端点Anthropic Messages 协议
Agent + 模型 ↓ Unreal Editor
  1. 01
    在编辑器偏好设置中添加模型Shuttlegent › General › Models：填写名称、Model Id、地址、协议与 Api Key。
  2. 02
    点“检测连接”逐个模型确认能连通；内置的两个 DeepSeek 模型共用一个密钥。
  3. 03
    在输入框下方选择 Agent、模型与模式Agent 在发出第一条消息后锁定；模型与推理强度在回合之间随时切换。

配置在编辑器内完成，本网页不收集密钥。

序章 / 一次穿行的开始
GET STARTED

装进你的编辑器。

  1. 01
    放入插件将 Shuttlegent 放到项目的 Plugins 目录，在 .uproject 中启用。
  2. 02
    构建运行时并编译 Editor按插件 README 打包运行时，再编译项目的 Editor。
  3. 03
    填写模型密钥编辑器偏好设置 › Shuttlegent › General › Models，填好后点“检测连接”。
  4. 04
    打开面板，开始对话窗口 › Shuttlegent。先用只读任务熟悉流程，再确认需要的修改。

支持 UE 5.8 / Windows；具体构建要求以插件 README 为准。
